# App Base — Semana 2

## Para os estudantes

Olá! O **`app-base`** é o projeto base da disciplina **DESENVOLVIMENTO DE API BACK-END**, preparado para **uso em sala de aula**.

Ele serve de **referência** para os exercícios da Semana 2 (Aula 02), em que trabalhamos os métodos HTTP básicos (**GET**, **POST**, **PUT** e **DELETE**), cada um retornando uma mensagem **Hello**.

### Slides da aula

Use junto com o código o material teórico da **Aula 02**:

**Aula 02 — DABE — HTTP, HTTPS, REST** (Prof. Lucas Carvalho)

Os slides estão disponíveis na **página do curso** (material da Semana 2).

### Onde baixar o app-base

Você pode baixar o projeto:

1. Na **página do curso** (material da Semana 2)
2. No **GitHub** do professor:  
   https://github.com/prof-carvalholucas/DESENVOLVIMENTO-DE-API-BACK-END

Pasta do projeto no repositório: `aula02/app-base`

### Tecnologias usadas

- **Node.js** — runtime no servidor  
- **npm** — gerenciador de pacotes  
- **NestJS** — framework para APIs  
- **TypeScript** — tipagem sobre JavaScript  

### Como começar

```bash
cd aula02/app-base
npm install
npm run start:dev
```

A API sobe em: `http://localhost:3000`

Use um cliente HTTP (Insomnia, Postman ou REST Client) para testar as rotas durante a aula.

Bons estudos!
